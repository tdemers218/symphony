# Phosphor Regular

This font contains the glyphs used by Symphony from [Phosphor Web v2.1.2](https://github.com/phosphor-icons/web/tree/v2.1.2/src/regular). The glyph outlines come from the upstream font. The MIT notice is in LICENSE.

Glyph mappings follow upstream style.css. The table lists the glyphs included in the font subset.
