# Symphony Manual

Symphony is a free, open-source 2D animation app. You draw frame by frame
or build rigs, time the animation in a Timeline or Xsheet, and composite
the shot in a node graph. It works the way Toon Boom Harmony works, so
Harmony habits carry over. It's built from Harmony's public documentation
and isn't affiliated with Toon Boom.

Symphony is in **preview**. What this manual describes is in the current
preview build. Anything that isn't built yet is marked **Planned**, and
[Planned features](planned.md) lists all of it in one place.

## Three things worth knowing first

- **Search does almost everything.** Press `Tab` and type what you want:
  an action ("insert 3 frames"), a node ("blur"), a layer, a colour or a
  brush preset. Results for the view under the pointer come first. If
  you don't know where something is, search for it.
- **Two shortcut profiles.** The **Symphony** profile (the default) uses
  plain letters that depend on the view under the pointer. The
  **Harmony** profile uses Harmony 27's default shortcuts. Switch in
  **Edit → Preferences → Workflow and shortcuts**.
- **Your work is autosaved.** If Symphony closes unexpectedly, it offers
  to recover what you hadn't saved the next time it opens. See
  [Projects, saving and recovery](projects.md).

## Platforms

Symphony runs on macOS, Windows and Linux. Pen pressure and tilt work on
macOS today. On Windows and Linux a tablet works as a mouse for now;
pressure support there is **Planned** (see [Pens and tablets](tablets.md)).
